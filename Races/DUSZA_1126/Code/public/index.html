    Súgó – a MineScript nyelv
    
          
    A robot soronként hajtja végre a programot. Minden sor egy utasítás, a blokkokat (az if, else és while törzsét) szóközös behúzás jelöli. Üres sor és tabulátor nem lehet a programban, a szavak között pontosan egy szóköz áll.
    
          
    Robotparancsok
    
          
    
            
    step forward n
    n mezőt lép előre. Falba vagy a térképen kívülre nem léphet.
    
            
    turn by n
    n negyedfordulatot fordul balra (az óramutatóval ellentétesen). A turn by 3 tehát jobbra fordulás.
    
            
    mine here
    Kibányássza az aranyat abban a mezőben, ahol áll.
    
            
    isThere w
    Megnézi a robot előtti mezőt: 0 = üres kamra, 1 = fal (a térkép széle is falnak számít), 2 = arany. Az eredmény true vagy false. Csak set utasításban használható: set van to isThere 2.
    
            
    print x
    Kiírja az értéket a konzolra.
    
          
    
          
    Változók és műveletek
    
          
    set x to érték – az érték lehet egy szám (0–100), true/false, egy változó, isThere w, not a vagy egy művelet: a + b, a - b, a * b, a = b, a <> b, a < b, a <= b, a > b, a >= b, a and b, a or b. Egy sorban legfeljebb egy művelet állhat.
    
          
    A változó típusa (egész vagy logikai) az első értékadáskor rögzül. A feltétel (if x, while x) csak egy logikai értékű változó vagy literál lehet.
    
          
    Példa
    
          
    set count to 0
set fal to isThere 1
set megy to not fal
while megy
  set arany to isThere 2
  if arany
    step forward 1
    mine here
    set count to count + 1
  else
    step forward 1
  set fal to isThere 1
  set megy to not fal
print count
    
          
    
          
    Lépések és ranglista
    
          
    Minden végrehajtott sor egy lépésnek számít. A ciklus törzse minden körben újra számít, a while sora minden feltétel-ellenőrzéskor. Az else sora csak akkor számít, ha az else-ág lefut. Legfeljebb 1000 sor hajtható végre.
    
          
    Minden befejezett futtatás eredménye a ranglistára kerül. A szerver maga is lefuttatja a programot, így csak a valódi eredmény számít. A leállított futtatások nem kerülnek be.
